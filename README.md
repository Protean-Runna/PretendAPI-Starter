# PretendAPI

Honestly, this is my personal starter, of sorts, for small node.js API projects

I'll clone this repo for every time I want to experiment with APIs for:

*  firebase
*  mongoDB

Templates for either ready to mess with, without the boilerplate fluff.

It's probably not efficient to have both in the same template but if I want to focus on one or the other, I'll just remove what I don't need.

### Why this exists

I just get bored of setting up all the same dependencies, remaking the same controllers, routes and setting it all up. So why not skip that part for future me whenever he wants to make a new api project?

### Setting Up

```
git clone https://github.com/Protean-Runna/PretendAPI-Starter.git
cd PretendAPI-Starter
npm istall
node index.js
```

Easy Peasy.

### Using this repo

1. Clone Repo
2. Experiment with making controllers, models and routes for a thing or two
3. finish it or leave it on the shelf to gather dust
4. Return to Step 1
